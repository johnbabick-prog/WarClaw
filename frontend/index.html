LAN Monitor Guide
What It Does

Scans the detected subnet from this machine, probes common operational ports, identifies likely services, and recommends useful follow-on apps.

How To Use It

Leave the network field blank to auto-detect the connected subnet, or enter a CIDR manually. Add extra ports as a comma-separated list for devices that use nonstandard ports, then click Scan LAN.

What You’ll See

The results panel shows the connected network name when available, the interface used, the probed ports, discovered hosts, open services, protocol hints, and AI-generated recommendations.

Traffic Monitor Guide
What It Does

Captures live traffic visible to this machine, groups it into conversations, builds a topology diagram, and decodes readable payloads when possible.

How To Use It

Optionally filter capture by port. Include ports keeps only traffic touching those ports. Exclude ports removes traffic touching those ports. Then click Start Capture.

Network Name

Traffic Monitor shows the connected network label from the most recent LAN scan. Run LAN Monitor first if you want the network or SSID shown alongside live capture stats.

? Help & User Guide Everything you need to know about WarClaw

What is WarClaw?

WarClaw is your ship's AI-powered operations console. It runs 100% locally on this server — no internet connection needed. It can discover every system on the ship's network, monitor data traffic, and create custom applications to help the crew work more effectively.

Getting Started

1
Scan the Ship LAN

Go to LAN Monitor and click Scan LAN. WarClaw will find all connected systems — navigation equipment, sensors, bridge systems, and more. This usually takes 10-30 seconds.

2
Monitor Traffic

Go to Traffic Monitor and click Start Capture. You'll see live data flowing between systems in human-readable format. Click AI Analysis to get a plain-English summary of what's happening.

3
Generate Apps

After scanning, WarClaw recommends apps based on what it found. Click Generate All Recommended in the LAN Monitor to create them all at once, or go to App Factory to build custom apps by describing what you need.

4
Talk to the AI Assistant

Open AI Assistant and ask questions in plain English. Examples: "What systems are on the LAN?", "Create a navigation dashboard", "Explain the NMEA data from 192.168.1.10".

Feature Guide

▣ Dashboard

Your home screen. Shows system status at a glance — whether the AI is online, how many hosts are on the LAN, active agents, generated apps, and system resources. Use the Quick Actions buttons to jump to common tasks.

◈ AI Assistant

A chat interface where you can ask the AI anything about your ship's systems. It understands NMEA navigation data, MODBUS sensor readings, IEC 61162 bridge protocols, and more. You can ask it to explain data, recommend integrations, or generate apps.

Tips: Click the suggestion chips above the chat to try common questions. The AI remembers your conversation, so you can ask follow-up questions.

⊕ LAN Monitor

Scans the ship's network to find every connected device. For each device, it shows open ports, detected protocols (NMEA, MODBUS, HTTP), and what the device likely is. You can click Stream on NMEA devices to see live navigation data, or MODBUS to probe sensor registers.

After scanning, WarClaw shows AI Recommendations — suggested apps you can generate with one click.

⬡ Traffic Monitor

Shows live data flowing between devices on the LAN. You'll see which systems are communicating, what protocol they're using, and the actual data being sent — decoded into human-readable format. Click AI Analysis to get a plain-English summary and app recommendations based on the traffic.

◉ Agents

Agents are automated monitors that run 24/7 watching ship systems. They track navigation data, engineering sensors, weather, and network activity — and alert you when something unusual happens (like losing GPS signal or a sudden depth change). Click Auto-Recommend to get agent suggestions based on your LAN scan.

⬢ App Factory

Describe an operational workspace you need in plain English, and WarClaw assembles a reliable live dashboard around the ship data it already knows how to expose. The result becomes a live web page accessible from any device on the ship's LAN.

▤ Reports

Generate summaries such as a daily OPORD-style report, watch handover brief, or network posture report. These are built from mission events, agents, generated apps, and recent operator activity.

⚙ Hardware / Model

Shows this server's hardware capabilities (CPU, RAM, GPU) and lets you manage the AI model. WarClaw automatically loads a model on startup, but you can switch models here if needed.

◎ Mission Log

A live timeline of everything WarClaw does — scans, agent alerts, app generation, system events. Useful for keeping a record of operations. You can export the log as a file for post-voyage analysis.

Common Questions

Does WarClaw need internet?

No. Everything runs locally on this server. No data ever leaves the ship's network.

What does "AI Model" mean?

The AI model is the brain that powers the chat assistant and app generation. It's a file stored on this server. WarClaw loads it automatically on startup.

What if the AI gives a wrong answer?

The AI is a tool, not an authority. Always verify critical information against your ship's instruments and standard procedures. The AI is best used for quickly understanding data patterns, building dashboards, and getting recommendations.

Can I access WarClaw from other computers on the ship?

Yes. Open a web browser on any computer connected to the ship's LAN and go to this server's address on port 7070 (shown in the header).

What protocols does WarClaw understand?

NMEA 0183 — Navigation data (GPS, heading, depth, speed, wind). MODBUS TCP — Industrial sensors and engineering systems. IEC 61162 — Bridge equipment data. HTTP — Web interfaces and APIs.

The traffic monitor says "requires elevated privileges"

Full packet capture needs administrator/root access. If you started WarClaw with sudo ./start.sh, it will have full access. Without sudo, the traffic monitor still works but with limited visibility.
